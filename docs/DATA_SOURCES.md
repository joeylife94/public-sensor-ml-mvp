## Data-use rules

1. Public sources only.
2. Record dataset ID, publisher, filename, retrieval context, file size, and SHA-256.
3. Do not commit large raw downloads.
4. Never import client/company data or derived samples.
5. Do not guess ambiguous source headers.
6. Preserve raw provenance separately from normalized/model-ready output.
7. Attribute Seoul Metropolitan Government in buyer-facing proof.
